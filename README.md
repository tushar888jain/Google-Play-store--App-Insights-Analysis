# Google Play Store App Insights Analysis

A data analytics case study on the Google Play Store dataset (Kaggle), exploring what drives app success on the platform — from ratings and pricing to app size, category performance, and user sentiment.

# Project Overview

This project takes a raw dataset of Google Play Store apps and user reviews and turns it into a clear, structured analysis. The goal was to understand what separates high-performing apps from the rest, and to surface insights that are useful for product and business decisions.

# What Was Done
1. Cleaned and prepared the raw app and review datasets, handling duplicates, missing values, and inconsistent formatting

2. Analyzed patterns across ratings, categories, pricing, app size, installs, and content ratings
Ran sentiment analysis on user reviews and compared it against star ratings

3. Compiled findings into a full written report with business impact for each insight
Built an interactive Power BI dashboard to make the analysis explorable

# Tools Used

Excel / Power Query for data cleaning, Power BI for the interactive dashboard  And Gen AI for sentiment analysis support.

Full findings and business impact are covered in the complete project report.
